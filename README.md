# MuseAI – Frontend (Angular)

Frontend del proyecto **MuseAI** (Angular, standalone).  


## Requisitos

- **Node.js**: ≥ 20.19 (o ≥ 22.12)
- **npm**: ≥ 10
- Angular CLI se usa vía `npx` (no requiere instalación global).
```

## Arranque rápido

```bash
# 1) Instalar dependencias (respetando package-lock)
npm ci

# 2) Servidor de desarrollo
npm start
# Abre http://localhost:4200
