# Contribuir a MuseAI

## Flujo de ramas
- `dev` → trabajo diario
- `qa` → control de calidad
- `main` → producción
Merge a `qa`/`main` solo vía PR con ≥1 aprobación y CI verde.

## Mensajes de commit
```
tipo: descripción breve
ej. feat: implementar login con JWT
```
Tipos: feat, fix, docs, style, refactor, test, chore.
